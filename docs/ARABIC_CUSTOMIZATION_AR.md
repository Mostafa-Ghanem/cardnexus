# التعريب والتخصيص للجمهور العربي — فرع `feature/arabic-customization`

هذا الفرع مبني على `release/hostinger-upload-v1` ويحافظ على نفس إعدادات النشر:
Next.js + Node 24 + MySQL عبر Prisma، و`experimental.cpus: 1` في `next.config.ts`،
وأمر البناء `npm run build` والمخرجات `.next`.

## ما الذي تغيّر

| المجال | التغيير |
|---|---|
| اللغة والاتجاه | `<html lang="ar" dir="rtl">`، وخط **IBM Plex Sans Arabic**، وتحويل فئات Tailwind الاتجاهية (`ml/mr/pl/pr/left/right`) إلى منطقية (`ms/me/ps/pe/start/end`). |
| الترجمة | كل الواجهات ولوحات التحكم ولوحة الإدارة ورسائل أخطاء الـ API والبريد الإلكتروني (RTL) وملفات CSV بالعربية. التواريخ بالعربية مع أرقام لاتينية (`ar-u-nu-latn`). |
| الهوية | الاسم والشعار واللون الأساسي تُقرأ من **لوحة الإدارة ← إعدادات المنصة**. اللون الافتراضي `#0F766E`. الاسم الافتراضي `كارت نكسس` (أو `NEXT_PUBLIC_APP_NAME`). |
| المحتوى | صفحة رئيسية وأسئلة شائعة جديدة، و«من نحن» و«سياسة الخصوصية» بدل Impressum/Datenschutz، وحذف ادعاءات «الخوادم في ألمانيا / DSGVO / Made in Germany». |
| الأسعار | العملة تظهر حسب `NEXT_PUBLIC_PRICE_CURRENCY` (الافتراضي USD). الأرقام في `lib/plans.ts`. **يجب أن تطابق أسعار Stripe/PayPal.** |
| جمع العملاء المحتملين | **متاح في كل الباقات بما فيها المجانية** (`leadCapture: true`). صفحة العملاء تعرض العملاء من كل بطاقات المستخدم. |
| تجربة الجوال | نموذج سفلي (bottom sheet): الاسم + الجوال + البريد (اختياري) مع `autocomplete` و`inputMode`، وتذكر بيانات الزائر على جهازه، وتحويل الأرقام العربية ٠١٢… إلى 0-9، والرسالة اختيارية ومطوية. أزرار أكبر، ومراعاة `safe-area`، وشريط حفظ ثابت في محرر البطاقة. |
| أرقام الهواتف في RTL | تُعزل داخل `<bdi>` حتى لا تنقلب (`+966…`). رابط واتساب مباشر لكل عميل محتمل. |

## إصلاحات أخطاء اكتُشفت أثناء الاختبار

1. **صفحات استعادة كلمة المرور والتحقق بخطوتين كانت تُحوَّل إلى `/login`** للمستخدم غير المسجل (حارس المسارات في `proxy.ts`). أصبحت `/forgot-password` و`/reset-password` و`/login/2fa` عامة.
2. **تنزيل vCard كان يفشل (500) مع الأسماء العربية** بسبب ترويسة `Content-Disposition`. أصبحت بصيغة RFC 5987.
3. **إنشاء أول بطاقة من المحرر كان يحفظ الاسم فقط** ويُسقط المسمى والجوال والبريد… أصبح يحفظ كل الحقول.

## متغيرات البيئة الجديدة (كلها اختيارية)

تُضاف من Hostinger ← Environment Variables. متغيرات `NEXT_PUBLIC_*` تُقرأ **وقت البناء**، لذلك أعد النشر بعد تغييرها.

| المتغير | الاستخدام |
|---|---|
| `NEXT_PUBLIC_APP_NAME` | الاسم الافتراضي للمنصة والبريد (إعدادات الإدارة تتقدم عليه). |
| `NEXT_PUBLIC_PRICE_CURRENCY` | عملة عرض الأسعار، مثل `SAR` أو `EGP` أو `AED`. |
| `NEXT_PUBLIC_SUPPORT_EMAIL` | بريد زر «اطلب الترقية» عندما لا تكون بوابة الدفع مُعدّة. |
| `NEXT_PUBLIC_DEMO_CARD_SLUG` | رابط بطاقة مثال في الصفحة الرئيسية (يختفي الزر إن كان فارغًا). |
| `NEXT_PUBLIC_WALLET_ENABLED` | `true` فقط بعد إعداد Apple/Google Wallet. |
| `NEXT_PUBLIC_DEFAULT_COUNTRY_CODE` | مفتاح الدولة لتحويل الأرقام المحلية (05…) إلى روابط واتساب، مثل `966` أو `20`. |
| `NEXT_PUBLIC_TURNSTILE_SITE_KEY` + `TURNSTILE_SECRET_KEY` | حماية نموذج العملاء من البرامج الآلية (Cloudflare Turnstile مجاني). |
| `TRUSTED_PROXY_HOPS` | عدد البروكسيات أمام التطبيق، `1` مناسب لـ Hostinger. |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_BOT_USERNAME` / `TELEGRAM_WEBHOOK_SECRET` | تنبيهات Telegram. السر من الحروف والأرقام و`_-` فقط. |
| `SKIP_DB_MIGRATIONS` | `true` فقط لتخطي الترحيل الإضافي (لا يُنصح به). |

## بعد النشر — من لوحة الإدارة

`/admin/settings`: غيّر **اسم التطبيق** و**الشعار** و**الأيقونة** و**بريد الدعم** و**نص التذييل**.
صف الإعدادات في قاعدة البيانات قد يحمل الاسم القديم `CardNexus`، لذلك غيّره من هنا مرة واحدة.

## قاعدة البيانات (ترحيل إضافي آمن)

أمر البناء `npm run build` يشغّل أولًا `scripts/db-additive-migrate.cjs`، وهو:

- **يضيف أعمدة ناقصة فقط**: لا يحذف ولا يعدّل ولا يعيد تسمية أي عمود، ولا يمس أي صف.
- **آمن للتكرار**: في كل نشر لاحق يطبع «schema already up to date» ولا يفعل شيئًا.
- إذا تعذّر الاتصال بقاعدة البيانات **يوقف البناء**، فيبقى الموقع الحالي يعمل على النسخة السابقة.
- لا علاقة له بالتهيئة الأولى: اترك `HOSTINGER_INITIAL_SETUP=false`.

الأعمدة التي يضيفها مرة واحدة:

| الجدول | العمود | الاستخدام |
|---|---|---|
| `twoFactor` | `failedVerificationCount INT DEFAULT 0` | إصلاح تفعيل التحقق بخطوتين |
| `user` | `telegramChatId` | تنبيهات Telegram |
| `Lead` | `status DEFAULT 'new'`، `note` | متابعة العملاء المحتملين (القديم منهم يصبح «جديد») |
| `Card` | `whatsapp`، `translations` | زر واتساب، والنسخة الإنجليزية |
| `Card` | `printDesign`، `extras` | تصميم الكارت المطبوع، وأقسام المعرض والفيديو والمواعيد والخريطة |

**قبل أول نشر لهذه النسخة خذ نسخة احتياطية** من phpMyAdmin (Export)، كإجراء احترازي.
تم اختبار الترحيل على قاعدة أُنشئت بالمخطط القديم وفيها بيانات: البيانات بقيت كما هي، و`prisma migrate diff` لم يجد أي فرق مع المخطط الجديد.

`better-auth` مثبّت على **1.6.22 بالضبط**: الإصدارات الأحدث تتطلب تغييرات أخرى في القاعدة.

## الإصلاحات الأمنية

| المشكلة | الإصلاح |
|---|---|
| أي مستخدم مسجّل كان يقدر يقرأ قائمة **كل المستخدمين** وبريدهم من `GET /api/users` | يرجع 403 لغير مديري المنصة والمؤسسات، ويعيد حقولًا محددة فقط (بدون معرّفات Stripe/PayPal) |
| تجاوز حد إرسال العملاء المحتملين بتزوير `X-Forwarded-For` | قراءة عنوان الزائر من يمين الترويسة (`TRUSTED_PROXY_HOPS`)، وحد لكل بطاقة مخزّن في القاعدة (30/ساعة)، وحقل خفي لصيد البرامج الآلية (honeypot)، وCloudflare Turnstile اختياريًا |
| تصدير CSV من صفحة العملاء كان يسمح بحقن صيغ Excel من بيانات الزائر | يستخدم الآن نفس المولّد الآمن، والأرقام الدولية تظهر بدون علامة `'` |
| حذف مستخدم كان يعرض رسالة الخطأ الداخلية | رسالة عامة فقط، والتفاصيل في السجل |
| مفاتيح API كانت تُنشأ ولا يقبلها أي مسار | أصبح لها API فعلي: `GET /api/v1/leads` |
| ترويسات Webhooks باسم قديم `X-FreddieCard-*` | `X-Webhook-Signature` / `X-Webhook-Timestamp` / `X-Webhook-Event` |
| فحوصات CI لا تعمل على فروعك | تعمل على `release/**` و`feature/**`، وتختبر الترحيل الإضافي واختبارات E2E |

## مزايا جديدة

- **زر «راسلني واتساب»** أخضر بارز في البطاقة برسالة جاهزة. يستخدم حقل «واتساب» في المحرر، أو رقم الجوال إن كان بالصيغة الدولية.
- **متابعة العملاء المحتملين**: حالة (جديد / تم التواصل / مهتم / تم الإغلاق بنجاح / غير مهتم) وملاحظة خاصة، وفلترة بالحالة، وأزرار واتساب واتصال وبريد بلمسة، والحالة داخل ملفات CSV.
- **تنبيه Telegram فوري** مع كل عميل جديد ورابط واتساب للرد. الإعداد: أنشئ بوتًا من @BotFather، وأضف متغيرات `TELEGRAM_*`، وأعد النشر، ثم اضغط «تفعيل البوت» في `/admin/settings`. كل مستخدم يربط حسابه من «الإعدادات ← ربط Telegram».
- **بطاقة بلغتين**: تبويب English في المحرر مع معاينة إنجليزية مباشرة. يظهر للزائر زر «عربي / English»، وتُفتح الإنجليزية تلقائيًا لمن لغة متصفحه ليست العربية، أو عبر الرابط `?lang=en` (وعنوان الصفحة أيضًا بالإنجليزية). في وضع English تتحول كل نصوص البطاقة الثابتة في كل القوالب، والأزرار، ونموذج «Leave your details» ورسائل الخطأ، ونافذة QR. الاستثناء الوحيد: اسم المنصة نفسه إن كان عربيًا (يمكن تغييره من إعدادات الإدارة).
- **Google Sheets**: في «الإعدادات ← Webhooks» دليل وكود Apps Script جاهز للنسخ، يضيف كل عميل محتمل كسطر في جدولك.
- **API للعملاء المحتملين** (لربط CRM أو Zapier أو Make):
  ```
  GET /api/v1/leads?since=2026-01-01T00:00:00Z&status=new&limit=100
  Authorization: Bearer fk_…
  ```

اختبارات المتصفح (mobile وenglish وstudio) تحتاج Playwright مثبتًا محليًا، ولا تعمل في CI.
CI يشغّل اختبارات الـ API واختبار الترحيل تلقائيًا على قاعدة MySQL مؤقتة.
لا تشغّل أي اختبار على الموقع الحقيقي: كلها تنشئ مستخدمين وبطاقات تجريبية.

## الحزم والثغرات

نُفّذ `npm audit fix` بدون `--force` (تحديثات متوافقة فقط)، ومنها:
`next` 16.3.8 → 16.4.4 (ثغرة حرجة)، `nodemailer` → 10.3.1، `node-forge` → 1.4.2.

المتبقي ولم يُرقَّ عمدًا:

| الحزمة | السبب |
|---|---|
| `zod` 3 → 4 | ترقية كبرى غير متوافقة. |
| `prisma` / `deepmerge-ts` | الإصلاح يتطلب Prisma 7 (ترقية كبرى)، والأداة تعمل وقت البناء فقط. |
| `better-auth` (عبر محولات drizzle/kysely) | الثغرة تخص PostgreSQL مع drizzle/kysely، ونحن نستخدم Prisma + MySQL. الترقية تتطلب تغيير القاعدة (انظر أعلاه). |
| حزم ESLint (`minimatch`) | أدوات تطوير فقط، ولا تُستخدم في التشغيل. |

## الدفعة الثالثة: واجهة احترافية واستوديو الطباعة

### استوديو الطباعة والهوية (`/card/print`)
- **12 تصميمًا للكارت الورقي بوجهين**: كلاسيكي، بسيط، ثنائي اللون، فاخر ذهبي، تقني، طبي، عقاري، محاماة واستشارات، مطاعم وكافيهات، بالصورة الشخصية، زخرفة عربية، تدرّج عصري.
- البيانات تُسحب من البطاقة الرقمية. يمكن تغيير:
  - الألوان، والخط (من 7 خطوط عربية)، والمقاس (85×55 أو 90×50 أو 89×51 مم).
  - اللغة: عربي، أو إنجليزي، أو أمامي عربي وخلفي إنجليزي.
  - الحقول الظاهرة، والجملة على الخلف، وشكل نقاط QR، ورمز NFC.
- الخلف فيه **رمز QR يفتح البطاقة الرقمية**. اختُبر بقارئ QR بالأشكال الثلاثة.
- طرق التصدير:
  - **PDF للمطبعة**: هوامش قص 3 مم وعلامات قص.
  - **PDF بالمقاس الدقيق**.
  - **لوح A4**: 10 كروت في الصفحة، والخلف معكوس للطباعة على الوجهين.
- الخطوط تُضمَّن في ملف PDF كخطوط حقيقية. لذلك اخترنا خطوطًا ثابتة غير متغيرة، لأن الخطوط المتغيرة تتحول إلى Type3 الذي ترفضه بعض المطابع.
- **رمز QR بهويتك**: بلون العلامة، وشعار في المنتصف، وإطار «امسحني»، وتنزيل PNG وSVG.
- **خلفية الاجتماعات**: صورة 1920×1080 فيها الاسم والمسمى ورمز QR، لـ Zoom وMeet وTeams.
- **الباقات**:
  - المجانية: 3 تصاميم مع اسم المنصة صغيرًا على الخلف.
  - Pro: كل التصاميم ولوح A4.
  - Business: طباعة كروت كل الفريق دفعة واحدة، لمدير الشركة فقط (`/print/team`).
  - التحقق من الباقة يتم على الخادم.

### واجهة المستخدم
- **معالج أول بطاقة من 3 خطوات**:
  - الخطوات: بياناتك ← الشكل ← النشر، وتنتهي بشاشة احتفال وروابط المشاركة.
  - عند رفع الشعار تُستخرج ألوانه تلقائيًا. الميزة نفسها موجودة في تبويب «التصميم» بالمحرر.
  - المعالج يظهر للمستخدم الجديد فقط. أعضاء المؤسسات يبقى لهم المحرر الكامل، وأي مستخدم يقدر يختار «أفضّل المحرر الكامل».
- **الصفحة الرئيسية**:
  - قسم أول جديد فيه جوال وكارت مطبوع متحركان.
  - قسم «جرّبها باسمك قبل التسجيل»: الزائر يكتب اسمه فيرى بطاقته في كل القوالب.
  - مقارنة بين الكارت الورقي وحده والكارت المطبوع مع الرقمي.
- **لوحة التحكم**:
  - 4 مؤشرات: الزيارات، وحفظ جهة الاتصال، والعملاء المحتملون، ونسبة التحويل. كل مؤشر مقارن بالشهر السابق.
  - رسم بياني لآخر 14 يومًا، وقائمة «أكمل بطاقتك». الأرقام تُحسب داخل MySQL.
- **العملاء المحتملون**:
  - عرض «لوحة» بأعمدة الحالات، والسحب والإفلات يغيّر الحالة. يعمل باللمس ولوحة المفاتيح.
  - تنبيه فوري داخل لوحة التحكم عند وصول عميل جديد، بفحص كل 30 ثانية والصفحة مفتوحة فقط.
- **البطاقة العامة**:
  - حركات دخول خفيفة. تُلغى تلقائيًا لمن فعّل «تقليل الحركة» في جهازه.
  - شريط سفلي ثابت على الجوال، فيه حفظ جهة الاتصال وواتساب وترك البيانات.
  - تبويب «إضافات» جديد في المحرر:
    - معرض أعمال حتى 12 صورة.
    - فيديو يوتيوب أو Vimeo.
    - مواعيد العمل مع شارة «مفتوح الآن» حسب المنطقة الزمنية للنشاط.
    - خريطة Google للعنوان.
- إصلاح وميض أيقونة الوضع الداكن، وكان يسبب خطأ hydration.
- صفحة الطباعة القديمة كانت لا تعمل: الأزرار بلا استجابة، والمقاس خاطئ. استُبدلت بالكامل.
